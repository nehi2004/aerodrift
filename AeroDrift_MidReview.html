Design decisions

Three choices that mattered

Direct vs transitive exposure

A naive "is there a path from the internet?" check flags every healthy 3-tier app, because web → app → db is a path. AeroDrift separates direct exposure (the instance's own security group accepts the internet) from transitive reachability, so the baseline raises zero false alarms.

Drift = diff of states

Instead of re-scanning rules, drift is the difference between two exposure maps. That makes detection fast (about a millisecond) and lets any two stored snapshots be compared later.

Concurrent ingestion

The four API fetchers are independent, so they run together. Measured: 0.181 s concurrent vs 0.868 s sequential, a 4.79× speedup, with simulated API latency.
